# Sheghlni (app)

The Next.js app lives in this folder. See the [repository README](../README.md) for setup, deployment, and demo instructions.

```bash
npm install
npm run download:photos   # curated Pexels assets (service-matched, ~1400px)
npm run dev
```

Open [http://localhost:3000/Sheghlni/](http://localhost:3000/Sheghlni/)
