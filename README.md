# Sheghlni — Services Marketplace

A high-fidelity frontend visualization of a two-sided services marketplace. Built with Next.js 14, TypeScript, Tailwind CSS, and shadcn/ui.

## Live demo

https://[your-github-username].github.io/Sheghlni/

Add `?demo=true` to any URL to show the **Demo mode** navigation pill (bottom-left) with quick links to all key flows.

Overview page: `/demo/?demo=true`

## Quick start

```bash
cd sheghlni
npm install
npm run download:photos   # first time — bundles category images locally
npm run dev
```

Open [http://localhost:3000/Sheghlni/](http://localhost:3000/Sheghlni/)

The app uses `basePath: /Sheghlni` for GitHub Pages. The root URL `/` will 404 locally — always include the base path.

## Tech stack

- Next.js 14 (App Router, static export)
- TypeScript
- Tailwind CSS + CSS custom properties
- shadcn/ui + Radix UI components
- Framer Motion animations
- Mock data layer (no backend required)

## Project layout

| Path | Description |
|------|-------------|
| `sheghlni/` | Next.js application |

| `.github/workflows/deploy.yml` | GitHub Pages deploy pipeline |

## Deploying

1. Push to `main` (or `master`) on GitHub.
2. In the repo go to **Settings → Pages → Source** and select **GitHub Actions**.
3. The workflow installs deps, downloads provider photos, runs `npm run build`, and deploys `sheghlni/out/`.

Manual trigger: **Actions → Deploy to GitHub Pages → Run workflow**.

## Build locally

```bash
cd sheghlni
# Stop dev server first — prebuild blocks if port 3000 is in use
npm run build
```

Static files are written to `sheghlni/out/`.

## Demo navigation

In development, a **Demo mode** pill appears automatically. On the live GitHub Pages site, append `?demo=true` once — it persists for the session via `sessionStorage`.

Use **Explore as Customer** or **Explore as Pro** on `/demo/` to set the mock role and jump to the right home screen.
